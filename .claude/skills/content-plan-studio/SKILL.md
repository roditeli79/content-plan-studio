# Скилл проекта «Контент-планер»

## Назначение

Поддерживать локальный веб-инструмент, который генерирует планы публикаций по встроенным правилам. НЕ заявлять, что это генеративный ИИ или что приложение использует API нейросети: в текущем MVP API нет.

## Структура

- `index.html` — форма ввода, карточки результата, кнопки экспорта.
- `styles.css` — адаптивный внешний вид.
- `script.js` — правила генерации, валидация, обработчики формы, экспорт CSV/JSON.
- `README.md` — описание, запуск и ограничения.
- `screenshots/example.png` — скриншот реального приложения.

## Запуск

1. Открой `index.html` в современном браузере (проект не требует сервера и зависимостей).
2. Укажи нишу, продукт и аудиторию, выбери цель, тон, дату, период и площадки.
3. Нажми «Собрать контент-план».
4. Проверь, что при выборе двух площадок на 7 дней создано 14 карточек.
5. Проверь скачивание CSV и JSON и корректность кодировки русского текста.

## Правила изменения

- Не добавляй платные сервисы, ключи API или облачную передачу данных без явного запроса.
- Не вставляй пользовательский ввод через `innerHTML`; используй безопасный `textContent`.
- Сохраняй возможность запуска `index.html` двойным щелчком.
- При изменении схемы плана синхронно обновляй CSV и JSON.
- После изменений тестируй минимум 7 дней × 2 площадки и сценарий без выбранной площадки.
- Не публикуй самостоятельно пользовательские данные, ключи, токены и рабочие материалы.
- Обновляй README и скриншот при изменении интерфейса.

## Критерии готовности

План реально создаётся, строки отображаются, файлы экспорта скачиваются, нет ошибок в консоли браузера, интерфейс пригоден для мобильного экрана.
